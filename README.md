\# QVAC Local Study Buddy



A simple local AI study assistant built with Tether's QVAC SDK.



The app runs AI inference directly on the device using QVAC. It loads a local Llama model and generates a study explanation without using a cloud AI API.



\## QVAC SDK



\- Package: @qvac/sdk

\- SDK version: 0.20.0

\- Model: LLAMA\_3\_2\_1B\_INST\_Q4\_0

\- Functions used: loadModel, completion, unloadModel



\## Requirements



\- Node.js 18 or newer

\- Windows, macOS, or Linux

\- Internet connection for the first model download
