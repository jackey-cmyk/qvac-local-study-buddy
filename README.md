\## 🧠 About



\*QVAC Local Study Buddy\* is a simple desktop AI study assistant built with \*Tether's QVAC SDK\* and \*Electron\*.



The application allows students to enter a question and receive an AI-generated explanation using a local Llama model.



Instead of sending the question to a cloud AI API, the application uses \*QVAC for on-device inference\*.



\*\*Local AI. Simple studying. No cloud AI API required for inference.\*\*
