\# 🚀 QVAC Local Study Buddy



A simple desktop AI study assistant built with \*Tether's QVAC SDK\* and \*Electron\*.



QVAC Local Study Buddy runs AI inference \*directly on the user's device\* using a local Llama model. The application provides a simple study interface where users can ask questions and receive AI-generated explanations without relying on a cloud AI API.



\## ✨ Features



\- 🧠 Local AI inference with Tether's QVAC SDK

\- 💻 Electron desktop application

\- ⚡ Streaming AI responses

\- 📚 Simple study-focused interface

\- 🔒 QVAC inference runs locally on the device

\- 🌐 Internet connection required only for the initial model download

\- 🎨 Clean and responsive desktop UI
